# Программирование на Python. Итоговое задание.
## Касьянов Павел Романович

В данной папке Вы можете найти следующие файлы:
  - main.py - скрипт для анализа угроз кибербезопасности.
  - logs/alerts-only.json - логи Suricata, использованные для анализа.
  - output/report.json - JSON-отчёт с результатами анализа.
  - output/report.png - график с визуализацией угроз.

## Описание

Скрипт получает данные из двух источников (логи Suricata + API VirusTotal), анализирует их, имитирует реагирование на угрозы (блокировка IP, уведомление по email) и сохраняет отчёт с графиком.

Этапы работы:
1. **Сбор данных** — загрузка алертов из `logs/alerts-only.json`, проверка подозрительных IP через VirusTotal API.
2. **Анализ данных** — определение топ IP-адресов и сигнатур, выявление IP с частыми алертами.
3. **Реагирование на угрозы** — имитация блокировки подозрительных IP и отправки email-уведомления.
4. **Отчёт и визуализация** — сохранение результатов в `output/report.json` и графика в `output/report.png`.

## Логика отбора подозрительных IP и реагирования

1. Из логов Suricata подсчитывается количество алертов для каждого source IP (`df["src_ip"].value_counts()`).
2. IP считается подозрительным, если число его алертов >= `ALERT_THRESHOLD` (по умолчанию 2). Такие IP блокируются (имитация — вывод в консоль).
3. Эти же подозрительные IP отправляются на проверку в VirusTotal API (`/api/v3/ip_addresses/{ip}`), до 5 штук за запуск (ограничение бесплатного тарифа — 4 запроса в минуту, при превышении лимита скрипт ждёт и повторяет запрос). Результаты VT (число детектов `malicious`, страна) сохраняются в отчёт как дополнительное подтверждение угрозы.
4. По всем заблокированным IP формируется имитация email-уведомления.

## Ключевые переменные

| Переменная | Значение | Описание |
|---|---|---|
| `VT_API_KEY` | из переменной окружения | API-ключ VirusTotal. Если не задан, проверка через VT пропускается |
| `ALERT_THRESHOLD` | `2` | Минимальное число алертов с одного IP, чтобы считать его подозрительным |
| `VT_MALICIOUS_THRESHOLD` | `3` | Минимальное число детектов `malicious` в VirusTotal для блокировки IP |

## Запуск

Без VirusTotal:
```bash
python main.py
```
С проверкой IP через VirusTotal:
```bash
VT_API_KEY=<ваш_ключ> python main.py
```

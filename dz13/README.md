# Программирование на Python. Домашнее задание 13.
## Касьянов Павел Романович

В данной папке Вы можете найти следующие файлы:
  - main.py - скрипт для загрузки файла на VirusTotal и получения результата сканирования.
  - 123.txt - тестовый файл для проверки.
  - response.json - JSON-ответ от API VirusTotal.

## Запуск
Запуск:
```bash
VT_API_KEY=<ваш_ключ> python main.py <путь_к_файлу>
```
Пример:
```bash
VT_API_KEY=abc123def456 python main.py 123.txt
```
